# Bell-pair adapter logical-error-rate experiments

This suite measures decoded logical `XX`/`ZZ` parity-measurement failures for an
adapter joining two binary stabilizer CSS blocks. It includes Surface–Steane and
HGP-simplex/surface presets, but the circuit builder accepts general compatible
CSS codes. See the [detailed experiment guide](GUIDE.md) for the circuit phases,
noise definitions, decoder, and interpretation of the reported LER.

Tests are beside their corresponding scripts. Existing filenames are retained
inside these directories. The [command migration map](COMMANDS.md) lists every
old-to-new module path; five main entry points retain compatibility launchers.

## Start a fresh pilot

From the repository root, install the package and plotting/profiling dependencies
in your Python environment: `python -m pip install -e . matplotlib psutil`.
These runners currently use POSIX file locking for checkpoint protection.

```bash
PYTHONPATH=src:. OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1 \
  python -m experiments.bell_pair_adapter_ler.pilots.run_ppm_basis_first \
  --code-pair hgp-simplex-surface --simplex-m 3 --surface-distance 4 \
  --preparation-rounds 4 --rounds 4 --bases X \
  --max-shots 100 --num-workers 1 \
  --output-dir experiments/bell_pair_adapter_ler/outputs/my_pilot \
  --build-only
```

Remove `--build-only` to sample. Repeat the same command to resume; `--max-shots`
is the cumulative cap, not additional shots. Checkpoint batches already flushed
to disk survive interruptions; unfinished batches may be lost.

The matching-basis convention uses local X→Z for XX and Z→X for ZZ, with Bell
extraction X→Z in both cases. The pilot defaults to intrinsic hardware-only
adapter noise with inactive-detector reduction. It retains the code blocks and
their ideal operations; this is not the same noise experiment as full surgery.

Fresh pilots and fidelity sweeps do not require archived data. For a fresh
physical-noise comparison, pass `--without-archived-references`. Historical
comparison/continuation runners do require the reference files identified in
their guides or command-line arguments; these files are not generated by an import.

## Outputs and checkpoint compatibility

All existing output directories stay under this package's `outputs/` directory.
The shared `common.paths.OUTPUT_ROOT` preserves that location regardless of where
a script now lives. This reorganization neither moves nor rewrites old results.
New output files are ignored by Git; previously committed results remain tracked.

Circuits, ordered detector models, decoder settings, and Sinter task IDs are
unchanged by the move. Source-hash telemetry now locates the actual implementation,
not a compatibility launcher. Original archive provenance is never rewritten.

The single-fault audit also pins its own source hash. It accepts precisely the
reviewed pre/post-reorganization hash pair in `common/source_relocations.json`
when **all other identity fields still match**, writing a separate
`source_relocation.json` receipt on resume. Circuit, catalogue, and runtime checks
remain mandatory. Unknown source edits remain rejected. Other source-pinned
distance and decoder search implementations were moved without changing their bytes.

## Tests

Install `pytest` and `pytest-socket` in the same environment, then run:

```bash
PYTHONPATH=src:. MPLBACKEND=Agg OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1 \
  python -m pytest -q experiments/bell_pair_adapter_ler
```

The normal suite builds temporary synthetic references and needs no simulation
outputs. The small `common/reorganization_baselines.json` fixture contains only
circuit/DEM/task hashes from commit `30c6a55f`, not sampled LER data.

If the historical local archives are available, also validate them explicitly:

```bash
PYTHONPATH=src:. MPLBACKEND=Agg OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1 \
  python -m pytest -q experiments/bell_pair_adapter_ler \
  --adapter-archives -m adapter_archive
```

Archive validation is read-only. Missing archives are not silently replaced with
new simulations. No test starts a production-length sampling run.
